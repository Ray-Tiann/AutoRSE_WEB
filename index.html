01 The question

Better scores.
But where do the
better ideas come from?

LLM agents can write code and run experiments. Can they autonomously improve the algorithms behind recommender systems?

AutoRSE evaluates this ability on existing recommendation baselines. We measure final performance and inspect the full optimization trajectory to understand what agents change, how they improve, and where they fall short.

Beyond the final score

Novelty and performance
move together.

Higher novelty scores are associated with larger relative performance gains (Pearson r = 0.79). This motivates testing whether better ideas can help agents go further.

Novelty is assessed on a 0–4 ordinal scale. The relationship is an association, not a causal estimate.

06 RQ3 · Idea injection

Better ideas give agents
more room to improve.

We compare standard execution, explicit self-generated ideation, and an external library of research ideas.

+13.35%

mean test-score improvement over
the self-generated-ideas setting

Execution is only part of the challenge.

With externally supplied ideas, agents achieve higher scores on all six tasks in this experiment. The result points to idea generation as an important bottleneck for autonomous recommendation improvement.

Controlled comparison: Claude Code × DeepSeek V4 Flash, with three independent trials. This result is specific to this LLM–harness pairing.
