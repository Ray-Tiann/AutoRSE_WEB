Training and content representations

Standard · Claude Code × Claude Opus 4.8

Change

Compare two independent variants of the same HSTU control: cosine learning-rate decay with warmup, and a learnable projection of the supplied frozen 768-dimensional item features into the ID embedding space.

Observed result

Validation NDCG@10: control 0.06770; training schedule 0.06997; content fusion 0.07216.
